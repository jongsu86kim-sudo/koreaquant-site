개인정보처리방침

시행일: 2026년 10월 31일 · 현재 정적 안내 웹페이지 기준

1. 프로젝트 및 적용 범위

KoreaQuant는 개인용 한국 주식 데이터 연구·백테스트 프로그램을 개발하는 프로젝트입니다. 현재 공개된 이 웹사이트는 정적 소개 페이지이며 회원가입, Google 로그인, Google Drive 파일 업로드·조회 기능을 제공하지 않습니다. 향후 인증 기능이 활성화되기 전에 이 방침을 실제 처리 구조에 맞게 갱신합니다.

2. 현재 웹사이트에서 처리하는 정보

이 웹사이트는 방문자가 입력하는 개인정보를 직접 수집하는 폼을 운영하거나 별도 방문자 분석 스크립트 및 광고 추적 코드를 설치하지 않습니다. 페이지는 GitHub Pages에서 제공하며, 접속 과정에서 서비스 제공자가 보안 및 운영 목적의 기술적 기록을 처리할 수 있습니다. 해당 처리에는 GitHub의 개인정보 정책이 적용될 수 있습니다.

3. 향후 Google Drive 연동 계획

향후 본인이 Google 계정 연결에 동의하는 경우에 한하여, 프로젝트 연구 데이터를 저장·읽고 복구하기 위한 Google Drive API 연동을 구현할 예정입니다. 검토 중인 권한은 https://www.googleapis.com/auth/drive.file이며, 앱에서 생성하거나 사용자가 명시적으로 허용한 파일로 접근 범위를 제한할 계획입니다. 현재 이 기능은 공개 웹사이트에서 제공하지 않으며 Google Drive 데이터는 이 웹사이트를 통해 수집되지 않습니다.

4. 향후 인증정보·저장·제공

Google Drive 연동이 실제 제공되는 경우 인증정보는 공개 코드나 일반 로그에 포함하지 않고 안전한 비밀 관리 수단에서 취급하도록 설계합니다. 프로젝트용 데이터는 사용자가 관리하는 저장소에 기록하도록 계획하고 있습니다. 실제 사용되는 외부 처리자, 접근 범위, 보존 기간 및 삭제 절차는 서비스 사용 전에 이 방침에서 구체적으로 안내합니다. Google 사용자 데이터를 광고나 판매에 이용할 계획은 없습니다.

5. 문의 및 권한 철회

일반적인 프로젝트 문의는 공개 GitHub Issues에서 할 수 있습니다. 공개 게시판에는 개인정보, API 키, OAuth 토큰, 계좌정보 등을 올리지 마세요. Google 계정 연동이 제공될 경우 사용자는 Google 계정의 연결 관리에서 앱의 권한을 철회할 수 있습니다. 저장된 개인 Drive 파일의 삭제는 사용자가 직접 관리할 수 있습니다.

6. 방침 변경

개인정보 처리 기능과 실제 운영 방식이 변경되는 경우 공개 페이지에 변경된 내용을 반영합니다. 이 방침은 현재 안내 웹사이트의 기능을 기준으로 작성되었으며, 계획 중인 연동 기능을 이미 제공한다는 의미가 아닙니다.
